# Запуск сборки сайта

Установите пакеты

```
deno i
```

Запустите сборку и в директории `./dist` будут лежать всё что вы должны распространять через любой веб сервер.

```
deno run build
```

Если вам нужно посмотреть правки в дизайне можете запустить мини веб сервер

```
deno run dev
```
